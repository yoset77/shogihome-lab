# PWA 更新の適用

セルフホストでも、Server の配布更新と各 Browser の更新検知は同時ではありません。
Service Worker が有効な通常タブ・インストール済み PWA では、作業を中断しないよう
更新を通知し、利用者が選んだ画面だけを再読み込みします。通知を閉じても、
ファイルメニューの「アプリを更新…」から案内を再表示できます。
HTTP の LAN IP 接続など、Service Worker が利用できない環境には適用しません。
更新版を検知しても、その画面がまだ Service Worker の制御下にない場合は通知しません。
制御下に入った次の読み込みで改めて通知します。共有リンク (`usen` など) の URL は、
実際に再読み込みするときまで変更しません。

対局・解析・検討や編集中の画面、未保存の定跡がある場合は適用を延期します。
Server ジョブは終了するか、対応する機能の既存デタッチ操作で画面から切り離してください。
更新処理が暗黙にジョブを停止・デタッチしたり、人間参加対局を再作成したりはしません。
棋譜は再読み込み直前にも Browser storage へ確定し、保存や SW 有効化に失敗した場合は
強制的な再読み込みへフォールバックしません。

SW の有効化は同一 origin の他の画面にも及びますが、それを他画面の再読み込み許可とは
扱いません。旧版からの初回移行では旧版の更新処理が動くため、作業を保存して全画面を
閉じてから更新する運用が必要です。任意の旧フロントエンドと新 Server の API 互換性や、
Server 再起動を越えた揮発性ジョブの保持を保証する機能ではありません。

画像キャッシュの拡張や自動更新への復帰は対象外です。
実装は [更新制御](../../shogihome/src/renderer/store/pwa.ts) と
[SW 登録](../../shogihome/src/renderer/webapp/update.ts)、生成設定は
[vite.config-pwa.mts](../../shogihome/vite.config-pwa.mts) を参照してください。
