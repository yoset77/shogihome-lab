# モバイルUI

## 目的と対応範囲

スマートフォンやタブレットの縦長画面で、盤面と棋譜・検討結果をタッチ操作で利用することを主な用途とします。モバイル専用の横長レイアウトは持たず、縦長モバイルUIとPC版UIに保守を集約します。

モバイルUIの正式サポートは縦長画面です。横長でも表示・操作を遮断しませんが、盤面の操作性やダイアログの配置は保証対象外です。大型タブレットの横持ちはPC版UIを推奨します。端末の物理サイズによる自動判定は行いません。

## 判断基準

- スマートフォン横持ちでは画面高が不足し、表示を収めても盤面・操作領域が小さくなります。
- 横配置のメイン画面と各ダイアログを継続して最適化するより、縦長モバイルUIとPC版UIに保守・検証を集約します。
- 非サポートと操作禁止は分けます。セルフホストで更新時期を選べるため、利用の選択はユーザーに委ねます。
- 操作ガード、回転によるPC版への自動切り替え、方向固定は導入しません。

## 回転と状態の扱い

回転は表示条件の変化として扱い、利用中のタブ・入力・編集状態を失う理由にしません。自動的な再読み込みやUIモード切り替え、対局・検討・時計の停止も行いません。横長画面を最適化しない方針と、進行中の操作を壊さないことは別の判断です。

具体的な配置・サイズ計算は [`MobileLayout.vue`](../../shogihome/src/renderer/view/main/MobileLayout.vue) と [関連テスト](../../shogihome/src/tests/renderer/view/main/MobileLayout.spec.ts) を正本とします。横長画面での最小操作サイズや全ダイアログの最適化は保証対象に含めません。
