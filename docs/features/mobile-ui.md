# モバイルUI

## 目的と対応範囲

スマートフォンやタブレットの縦長画面で、盤面と棋譜・検討結果をタッチ操作で利用できるUIを提供します。モバイル専用の横長レイアウトは廃止し、画面方向にかかわらず縦積み表示に統一します。

モバイルUIの正式サポートは縦長画面です。横長でも表示・操作を遮断しませんが、盤面の操作性やダイアログの配置は保証対象外です。大型タブレットの横持ちはPC版UIを推奨します。端末の物理サイズによる自動判定は行いません。

## 判断基準

- スマートフォン横持ちでは画面高が不足し、表示を収めても盤面・操作領域が小さくなります。
- 横配置のメイン画面と各ダイアログを継続して最適化するより、縦長モバイルUIとPC版UIに保守・検証を集約します。
- 非サポートと操作禁止は分けます。セルフホストで更新時期を選べるため、利用の選択はユーザーに委ねます。
- 操作ガード、回転によるPC版への自動切り替え、方向固定は導入しません。

## 表示と状態

- 通常時は、盤面、操作ボタン、下部表示、タブ選択を縦に並べます。
- 下部表示は棋譜、コメント、情報、PV、思考、DB、グラフ、定跡です。思考・定跡タブの表示は既存設定に従います。
- 評価問題では操作ボタン・通常タブの代わりに問題欄を表示します。
- 回転やウィンドウサイズ変更はサイズの再計算だけを行い、選択中のタブを維持します。回転を理由にメイン画面やダイアログを再生成・破棄せず、入力・編集状態を保持します。
- 回転による再読み込み、対局・検討の停止、時計の一時停止は行いません。
- 初期表示や高さ不足時も、盤面・下部表示に負のサイズを渡しません。ただし、横長画面での最小操作サイズや全ダイアログの表示最適化は保証しません。

## PC版への切り替え

既存の「設定」から「UIモード」を「PC」に変更し、ページを再読み込みします。再読み込みで失われる状態があるため、編集内容を保存し、対局・検討を終了してから切り替えます。モバイルUIとPC版UIの起動時判定・設定・URL仕様は変更しません。

## 検証

- `shogihome/src/tests/renderer/view/main/MobileLayout.spec.ts`: 縦長・横長・正方形の縦積み表示、従来の縦長サイズ配分、代表的なタブの回転時の維持、高さ不足時のサイズ計算、評価問題。
- ブラウザー確認では、縦長画面の主要操作、ダイアログを開いたままの回転・復帰と入力状態、大型タブレット横持ちでのPC版の主要操作を確認します。

横長モバイルで全ダイアログの表示乱れを解消することは、この方針の検証対象には含めません。
