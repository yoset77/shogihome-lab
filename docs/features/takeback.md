# 人間対AIの「待った」

## 目的と対象

練習対局で、人間が最後に指した手を指し直せるようにします。戻り先は任意の手数ではなく、最後の人間の判断をやり直せる時点です。人間対LANエンジンを対象とし、人間同士・AI同士・終局後の汎用的な巻き戻しは扱いません。

## 棋譜と時計を一緒に戻す理由

局面だけを戻すと、取り消した手の消費時間・加算・秒読みが残り、同じ判断をやり直すための状態になりません。棋譜と双方の時計を一つの復元単位とし、取消や再接続の待ち時間も指し直しの負担にしません。

今回の対局で生成した内容と、開始前からユーザーが持っていた棋譜・分岐を区別します。途中局面からの対局でも既存の注釈や分岐を壊さず、開始局面より前へは戻しません。

## 取消完了を待つ理由

同じ手を指し直すと局面文字列も同じになるため、局面の比較だけでは旧探索の結果を排除できません。待ったは結果を使う通常停止ではなく、旧探索の結果を使わない取消として扱います。

取消完了を確認するまで巻き戻しを公開しません。確認できない場合は元の進行を保って対局を中断し、engine状態が不明なまま指し直しを始めることを避けます。待ったを先に中断した場合も、後から届く取消完了を対局再開の指示にはしません。

巻き戻しの所有権・checkpoint・失敗時の契約は [Game Session Architecture](../architecture/game-sessions.md)、探索識別と取消境界は [Remote Engine Architecture](../architecture/remote-engine.md) を参照してください。
