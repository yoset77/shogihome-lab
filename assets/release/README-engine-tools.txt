ShogiHome Lab - エンジン側ツール (engine-tools)

本パッケージは、Webサーバーを別のPCやDockerで動かす構成向けの、
エンジンラッパー + 設定GUI のみの配布物です。
サーバーと同一PCで使う通常版とは異なり、サーバー本体は含まれていません。

同梱物:
  ShogiHomeLab.exe   設定エディタ (GUI)
  wrapper.exe        エンジンラッパー (TCP中継)
  engine-wrapper/    engines.json / .env / licenses

==================================================================
■ 1. エンジンを登録する

1.  本フォルダをターミナルで開き、次のコマンドを実行してください。
    --------------------------------------------------
    .\ShogiHomeLab.exe --config-editor
    --------------------------------------------------
    サーバーを起動せず、設定エディタのウィンドウだけが開きます。
    ウィンドウを閉じると終了します。

2.  「＋エンジン追加」ボタンを押し、エンジン名を入力して
    「参照...」からエンジンの実行ファイルを選択します。
3.  「オプション取得」ボタンを押すと、エンジンの設定項目が読み込まれます。
4.  必要に応じてエンジンオプションを調整し、「反映」をクリックします。
5.  「設定を保存」ボタンを押すと、登録が完了します。

==================================================================
■ 2. エンジンラッパーを起動する

1.  engine-wrapper/.env をテキストエディタで開き、以下の項目を設定します。

    # 別PCのサーバーから接続させる場合
    BIND_ADDRESS=0.0.0.0  # またはサーバーから到達できるIPアドレス
    LISTEN_PORT=4082
    WRAPPER_ACCESS_TOKEN=<生成した32文字以上のランダムな値>
    ※ ループバック以外で待ち受ける場合は、Windowsファイアウォールで
      wrapper.exe の通信を許可し、同じ信頼できるネットワーク内でのみ利用してください。
      32文字以上の認証トークンの設定が必要です（サーバー側の WRAPPER_ACCESS_TOKEN と
      一致させる必要があります）。

2.  「wrapper.exe」をダブルクリックして起動します。
    同梱の engine-wrapper/ の設定が自動で使われます。
    コンソールに起動ログが表示され、
    ウィンドウを閉じるとラッパーが終了します。

==================================================================
■ 3. サーバー側の設定

サーバー側の shogihome/.env に、以下を設定してサーバーを再起動します。

- REMOTE_ENGINE_HOST：エンジン側PCの、サーバーから到達できるIPアドレス
- REMOTE_ENGINE_PORT：ラッパー側の LISTEN_PORT と同じ値
- WRAPPER_ACCESS_TOKEN：ラッパー側と同じ値

==================================================================
■ 4. トラブルシューティング

Q. --config-editor を実行しても設定ウィンドウが出ない
A. 別のエディタが同じフォルダを開いている可能性があります。
   ターミナルに表示されたエラーを確認し、一方を閉じてから開き直してください。

Q. サーバーからエンジンに接続できない
A. 以下を確認してください。
   1. サーバーから到達できるアドレスで待ち受けているか
   2. ファイアウォールで通信を許可しているか
   3. 32文字以上のトークンが設定されていて、サーバー側の設定値と一致しているか
   4. サーバーの REMOTE_ENGINE_HOST がエンジン側PCのアドレスになっているか
   5. サーバーの REMOTE_ENGINE_PORT がラッパーの LISTEN_PORT と同じ値か
