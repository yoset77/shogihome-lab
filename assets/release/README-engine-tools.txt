ShogiHome Lab - エンジン側ツール (engine-tools)

本パッケージは、サーバーとは別のPC（またはDocker等）で将棋エンジンを
動かすための、wrapper + 設定GUI のみの配布物です。
サーバーと同一PCで使う通常版とは異なり、サーバー本体は含まれていません。

同梱物:
  ShogiHomeLab.exe   設定エディタ (GUI)
  wrapper.exe        エンジンラッパー (TCP中継)
  engine-wrapper/    engines.json / .env / licenses

==================================================================
■ 1. エンジンを登録する

1.  本フォルダをターミナルで開き、次のコマンドを実行してください。
    --------------------------------------------------
    .\ShogiHomeLab.exe --config-editor
    --------------------------------------------------
    サーバーを起動せず、設定エディタのウィンドウだけが開きます。
    ウィンドウを閉じると終了します。

    任意のフォルダの設定を編集する場合は、次のように実行します。
    --------------------------------------------------
    ShogiHomeLab.exe --config-editor --config-dir "D:\Engines\config"
    --------------------------------------------------
    編集対象は <config-dir>\engines.json です。相対パスのエンジンや
    オプション取得の作業フォルダも同じフォルダを基準にします。

    ※編集中のフォルダを別のエディタが同時に開いている場合、起動は
      エラーになります。ターミナルに表示されたメッセージを確認し、
      一方を閉じてから開き直してください。

2.  「＋エンジン追加」ボタンを押し、「参照...」からエンジンの実行ファイルを
    選択します。
3.  「オプション取得」ボタンを押すと、エンジンの設定項目が自動で読み込まれます。
4.  必要に応じてエンジンオプションを調整し、「決定」をクリックします。
5.  「設定を保存」ボタンを押すと、登録が完了します。

==================================================================
■ 2. wrapper を起動する

1.  engine-wrapper/.env をテキストエディタで開き、待ち受けと認証を確認します。

    # 同一PCのサーバーと組み合わせる場合
    BIND_ADDRESS=127.0.0.1
    LISTEN_PORT=4082
    # WRAPPER_ACCESS_TOKEN=secret-token-12345

    # 別PCのサーバーから接続させる場合
    # BIND_ADDRESS=0.0.0.0
    # LISTEN_PORT=4082
    # WRAPPER_ACCESS_TOKEN=secret-token-12345
    ※ 0.0.0.0 で待ち受ける場合は、Windowsファイアウォールで
      wrapper.exe の通信を許可し、同じネットワーク内でのみ利用してください。
      認証トークンの設定を推奨します（サーバー側の WRAPPER_ACCESS_TOKEN と
      一致させる必要があります）。

2.  「wrapper.exe」をダブルクリックして起動します。
    同梱の engine-wrapper/ が自動で使われます。
    黒いウィンドウ（コンソール）に起動ログが表示され、
    ウィンドウを閉じると wrapper が終了します。

    ポートや設定場所を変える場合などは、ターミナルから次のように起動します。
    --------------------------------------------------
    wrapper.exe --config-dir ".\engine-wrapper"
    --------------------------------------------------

==================================================================
■ 3. トラブルシューティング

Q. --config-editor を実行しても設定ウィンドウが出ない
A. 別のエディタが同じフォルダを開いている可能性があります。
   ターミナルに表示されたエラーを確認し、一方を閉じてから開き直してください。

Q. サーバーからエンジンに接続できない
A. 以下を確認してください。
   1. wrapper が起動しているPCで、待受アドレスとポートを確認する。
   2. 別PC構成では BIND_ADDRESS=0.0.0.0 とファイアウォール許可を確認する。
   3. トークンを設定した場合は、サーバー側の設定値と一致を確認する。
   4. エンジンのパス設定は、wrapper が動いているPC上のパスで登録する。
