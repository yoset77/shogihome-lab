ShogiHome Lab - ユーザーガイド

本ソフトウェアは、ShogiHome (https://github.com/sunfish-shogi/shogihome) をベースに、
リモートエンジンやサーバー側棋譜管理などの機能を実装したクライアント・サーバー型のアプリケーションです。
PC上のサーバーにブラウザからアクセスすることで、デバイスを選ばずに将棋の研究が行えます。

======================================================================================================
【重要】セキュリティに関する注意
このツールは、自宅のWi-Fiなど「信頼できるネットワーク内」での個人利用を前提としており、ログイン機能はありません。
不特定多数がアクセスできるネットワークや、インターネットに直接公開するサーバー等では絶対に使用しないでください。
外出先からはVPNを利用してください。
======================================================================================================

■ 1. 必要なもの

1.  このフォルダ一式（解凍済み）
2.  使いたい将棋エンジン（実行ファイルと評価関数）

■ 2. 最初の設定

1.  起動する
    一番上のフォルダにある「ShogiHomeLab.exe」をダブルクリックしてください。
    ランチャーが起動し、自動的にサーバーがバックグラウンドで開始されます。

    【重要】「WindowsによってPCが保護されました」と表示される場合
    インターネットからダウンロードした未署名のアプリを実行すると、青色の警告画面（SmartScreen）が表示されることがあります。
    その場合は「詳細情報」をクリックすると「実行」ボタンが表示されます。

    【重要】初回起動時の許可について
    起動時に「Windows セキュリティ」のポップアップが表示された場合は、
    「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」を押してください。
    ※自宅など信頼できるネットワークでは、Windowsのネットワーク設定が
      「プライベート」になっていることを確認してください。

2.  エンジンを登録する
    ランチャーの「エンジン設定」ボタンをクリックしてください。専用の設定画面が開きます。

    (1) 「＋エンジン追加」ボタンを押し、名前を入力して「参照...」からエンジンの実行ファイルを選択します。
    (2) 「オプション取得」ボタンを押すと、エンジンオプションが読み込まれます。
    (3) 必要に応じてエンジンオプションを調整し、「反映」をクリックします。
    (4) 「設定を保存」をクリックしたあと、エンジン設定画面を閉じます。

■ 3. 使ってみる

1.  アクセスする
    PCで使う: ランチャーの「PCで開く」をクリックすると、ブラウザでアプリの画面が開きます。
    スマホで使う: PCとスマホを同じネットワークに接続し、ランチャーのQRコードを読み取るか、表示されたURLをスマホのブラウザに入力してください。

2.  エンジンを使う
    「検討」や「対局」を開始する際、先ほど登録したエンジンを選択できます。

■ 4. 終了方法

1.  ランチャーの「停止して終了」ボタンをクリックしてください。
    すべてのバックグラウンドプロセスを安全に終了して閉じます。

    ※ 「×」ボタンで閉じるとタスクトレイに常駐します。完全に終了するには「停止して終了」を使用するか、
       タスクトレイアイコンから「終了」を選択してください。

■ 5. トラブルシューティング

Q. 画面が開かない / スマホからつながらない
A. 以下の2点を確認してください。

    1. Windowsのファイアウォール設定
       初回起動時のポップアップで「アクセスを許可する」を選択しなかった場合、通信がブロックされます。
       手動でWindowsファイアウォールの設定（「アプリにファイアウォール経由の通信を許可する」）を開き、
       「shogihome-server.exe」の通信を「プライベート」で許可してください。

    2. ネットワークの違い
       PCとスマホが同じネットワークに接続されているか確認してください。
       同じWi-Fiでも、ゲスト用ネットワークなどでは端末間の通信が制限される場合があります。

Q. エンジンが動かない
A. 登録した実行ファイルが正しいか確認してください。原因が分からない場合は、
   ランチャーの「ログ表示」からラッパーログを開き、エラーメッセージが出ていないか確認してください。

■ 6. 任意の設定

より詳細な設定は、ランチャーの「サーバー設定」ボタンから行えます。
設定を変更したら「保存」をクリックし、表示される確認画面でサーバーを再起動してください。

1.  サーバー側の棋譜フォルダを指定する
    「KIFU_DIR」にフォルダを指定すると、ブラウザからそのフォルダ内の棋譜や定跡を操作できるようになります。
    入力欄の右にある「参照...」ボタンでフォルダを選択できます。

    ※棋譜ファイルが大量にある場合、あらかじめフォルダに分けて整理しておくとスムーズです。

2.  エンジンの切断保護時間を変更する
    「ENGINE_CONNECTION_PROTECTION_TIMEOUT」は、検討中にエンジンとの接続が切れた場合に、
    サーバー側でエンジンを終了させずに再接続を待機する時間を設定します。
    スマホではブラウザのタブが非表示になると接続が切れることがあるため、
    検討中に別のアプリに切り替えたりする場合は、必要に応じてこの値を長め（例: 600秒）に設定してください。

■ 7. 外出先からの利用

1.  インターネット経由でのアクセス (Tailscale)
    Tailscale (https://tailscale.com/download) を利用して、外出先からアクセスできます。

    1.  サーバーPCとクライアントにTailscaleをインストールし、同一アカウントでログインします。
    2.  Tailscaleが割り当てたサーバーPCのIPアドレス (100.x.x.x) を確認します。
    3.  サーバーを起動します（TailscaleのIPは通常、自動的に認識・許可されます）。
    4.  クライアントから http://<TailscaleのIPアドレス>:8140 にアクセスします。

2.  ホーム画面に追加して使う (Tailscale Serve)
    Tailscale Serve を使うと、HTTPS化されたURLが発行され、PWAとしてホーム画面に追加できます。

    1.  Tailscale の AdminConsole で、「MagicDNS」と「HTTPS Certificates」を有効にします。
        MagicDNS のホスト名を、分かりやすい名前に変更しておくと便利です。

    2.  サーバーPCのターミナルで、以下のコマンドを実行します。
        --------------------------------------------------
        tailscale serve --bg 8140
        --------------------------------------------------

    3.  「サーバー設定」で、ターミナルに表示されたURL https://<hostname>.<tailnet>.ts.net を
        「ALLOWED_ORIGINS」の入力欄に追加します。

    4.  (推奨) セキュリティを高めるため、自動許可を無効化し Tailscale Serve の HTTPS URL からのアクセスに限定します。
        ※この設定後は、LAN や Tailscale IP の URL では接続できなくなります。

        「サーバー設定」で、以下の3点を設定してください。
        - BIND_ADDRESS を「127.0.0.1」に変更する
        - DISABLE_AUTO_ALLOWED_ORIGINS にチェックを入れる
        - TRUST_PROXY にチェックを入れる

    5.  「保存」後、サーバーを再起動し、https://<hostname>.<tailnet>.ts.net にアクセスして
        「ホーム画面に追加」します。
